# Security Policy

Please report vulnerabilities privately through the repository's **Security → Report a vulnerability** page (or by contacting the maintainer), not in a public issue. Include the steps to reproduce and the impact.

Only the latest version on `main` is supported.

Tips for users: keep Hugging Face tokens in the `HF_TOKEN` environment variable rather than on the command line, and be careful with audio from untrusted sources (ffmpeg decodes it).

`transcribe-server` now checks the API key and the upload size before it reads an upload, so unauthenticated or oversized uploads can no longer fill the disk, and it refuses playlists and manifests (HLS, DASH, ffconcat), which made ffmpeg open other files and URLs. Error responses no longer include temporary paths or ffmpeg's output: undecodable audio gets a 400 on every backend, and other failures a generic 500 whose details go to the server's log.

`transcribe` handles large batches better: `-f srt,json` (or `-f all`) writes several formats from one transcription, `--skip-existing` resumes a stopped run without transcribing the finished files again, and batch runs show an `[i/N]` line per file and a summary at the end, which Ctrl-C shows too before exiting with status 130. `transcribe -` reads audio piped into standard input, and `--json FILE` now works with `--outdir`.

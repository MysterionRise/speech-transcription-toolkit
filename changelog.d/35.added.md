Docker images run `transcribe-server` and `transcribe` without a Python setup: `ghcr.io/mysterionrise/speech-transcription-toolkit` for the CPU (no PyTorch) and its `:cuda` tag for NVIDIA GPUs, published with each release. They run as a non-root user, keep models in a `/models` volume and have a health check; the repository has a `docker-compose.yml` example. See [Docker](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/docs/docker.md).

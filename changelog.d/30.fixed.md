Network, authentication and file errors while loading the speaker-diarization model now raise `DiarizationError` (the original error is its `__cause__`) instead of whatever pyannote raised, so `transcribe --diarize` reports them as a one-line error. The warning that Canary or Voxtral reached their token limit now names the file also with speaker labels, when the backend gets the decoded samples, and a file object by its file name.

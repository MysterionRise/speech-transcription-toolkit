Folder scans leave out hidden files and the `._*` files macOS writes on other disks, and pick up more audio and video files (`.aif`, `.aiff`, `.amr`, `.caf`, `.m4b`, `.mka`, `.3gp`, `.avi`, `.m2ts`, `.m4v`, `.mpeg`, `.mpg`, `.mts`). Output files are written under a temporary name and then renamed, so Ctrl-C never leaves a half-written one, and on Windows a transcript redirected to a file or a pipe is written as UTF-8 instead of failing on characters the code page lacks.

A generic Hugging Face backend, `-b transformers -m <repo id or folder>`, runs most speech recognition models on the Hub through transformers' pipeline: Whisper fine-tunes and distil-whisper, CTC models such as wav2vec2 and MMS, Moonshine and other speech models. What each model can do (timestamps, word timestamps, a language, translation) is read from it once it has loaded. Install it with `pip install "speech-transcription-toolkit[transformers]"`; see [Backends](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/docs/backends.md#any-hugging-face-model-transformers).

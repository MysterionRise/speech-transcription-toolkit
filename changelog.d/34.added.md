A benchmark harness for contributors: `python -m benchmarks.run -b faster-whisper -m tiny`, run from a checkout, reports each model's word error rate, speed (RTFx) and peak memory on 100 LibriSpeech and 30 FLEURS clips, and a weekly workflow fails when the word error rate regresses. See [Benchmarks](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/docs/backends.md#benchmarks).

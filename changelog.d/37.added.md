`transcribe-server` streams transcripts: with `stream=true` and any model but `whisper-1`, which ignores `stream` as it does on OpenAI's API, `/v1/audio/transcriptions` answers with OpenAI's server-sent events, a `transcript.text.delta` per segment as the model transcribes it and then `transcript.text.done`, which OpenAI's SDKs read with `stream=True`. With `--diarize`, `response_format=diarized_json` gives OpenAI's diarized format, a segment per speaker turn. JSON responses have OpenAI's `usage`, the seconds of audio, and `/v1/audio/translations` takes `language`, the language translated from (an extension to OpenAI's API), with the new `--language` option as the server's default, so Canary translates from languages other than English. See [Streaming](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/docs/server.md#streaming).

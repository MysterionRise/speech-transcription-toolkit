Exceptions that tell failures apart: `BackendNotFoundError`, `BackendUnavailableError`, `ModelNotFoundError`, `ModelLoadError`, `AudioDecodeError`, `UnsupportedOptionError` and `DiarizationError`, all subclasses of `SpeechToolkitError` and of the built-in error raised before, so existing `except ValueError` (or `ImportError`, `RuntimeError`) code keeps working; library warnings are now `SpeechToolkitWarning`s. In batch mode, `transcribe` reports a file that fails with an unexpected error and carries on with the others instead of stopping.

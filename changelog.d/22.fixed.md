`ogg2wav` no longer overwrites one output with another when two inputs differ only in their extension, such as `talk.ogg` and `talk.opus`: they become `talk.ogg.wav` and `talk.opus.wav`, as `transcribe` names its outputs. It prints only the path of each WAV it writes to stdout, and skipped files go to stderr with the errors. faster-whisper now installs on Python 3.10 too: the PyAV version it was pinned to needs Python 3.11.

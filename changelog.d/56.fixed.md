On a computer with an NVIDIA GPU but without NVIDIA's CUDA 12 libraries (cuBLAS, plus cuDNN for CTranslate2 older than 4.6.3), faster-whisper no longer fails, or on Windows crashes, on the first transcription. It now warns, naming the missing libraries and how to install them, and runs on the CPU. With `--device cuda` it stops with that message instead. The [installation guide](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/docs/install.md#gpu) has a new GPU section for Windows and Linux.

**Breaking:** faster-whisper is now the default backend and comes with every install, so `pip install speech-transcription-toolkit` no longer installs PyTorch (several GB). OpenAI's Whisper moved to the `whisper` extra: to keep using it, `pip install "speech-transcription-toolkit[whisper]"` and pass `-b whisper` (or `backend="whisper"`). The model names are the same and the default is still `turbo`. The `voxtral` and `nvidia` extras now install PyTorch themselves, and the `faster-whisper` extra still works but adds nothing.

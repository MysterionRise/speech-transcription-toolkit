# Transcriber

`Transcriber` loads a model once and transcribes as many recordings as you give it; `transcribe()` loads a model and
transcribes one recording in a single call. Both are in
[speech_toolkit/api.py](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/speech_toolkit/api.py).
[Python API](../python-api.md) explains them with examples.

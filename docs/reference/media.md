# Decoding audio

`load_audio()` decodes audio or video with ffmpeg into the samples speech models take: a mono float32 NumPy array at
16 kHz. It is in
[speech_toolkit/media.py](https://github.com/MysterionRise/speech-transcription-toolkit/blob/main/speech_toolkit/media.py);
[Decoding audio](../python-api.md#decoding-audio) in the Python API guide shows how to use it.
